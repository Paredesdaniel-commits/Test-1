## KI – ein Feuerwerk an Möglichkeiten

Eine interaktive Webseite in einer einzigen Datei (`index.html`). Sie zeigt in vier Kapiteln, wie KI lernt, schreibt und malt. Alles läuft live im Browser, ohne externe Verbindungen.

👉 **Live ansehen:** https://paredesdaniel-commits.github.io/Test-1/

| Kapitel | Was passiert |
| --- | --- |
| Start | Tausende Lichtpunkte formen Wörter. Tippen, wischen, Handy neigen. |
| 01 · Lernen | Ein echtes neuronales Netz trainiert live und trennt Punkte. |
| 02 · Schreiben | Ein Mini-Sprachmodell wählt Wort für Wort, mit Temperatur-Regler. |
| 03 · Malen | Ein Bild entsteht Schritt für Schritt aus Rauschen. |
| 04 · Finale | Feuerwerk zum Antippen. |
